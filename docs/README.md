# API Documentation Bundle

This folder contains the API documentation assets added for bounty issue #32.

## Contents

- `API_REFERENCE.md` - Endpoint reference, auth model, error handling, rate limit notes, WebSocket integration notes, changelog.
- `sdk/javascript-typescript.md` - JavaScript/TypeScript integration guide.
- `sdk/python.md` - Python integration guide.
- `sdk/php.md` - PHP integration guide.

OpenAPI spec is published at `public/openapi.yaml`.

Interactive explorer is available at `public/api-explorer.html`.
